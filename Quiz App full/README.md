 Quiz App

 About the Project

Quiz App is an interactive programming quiz focused on web development.

I created this project independently while learning Web Development to practice and reinforce the knowledge I had gained.

The application allows users to test their programming knowledge through an interactive quiz system with score tracking.

Features

- 15 questions about programming, with a focus on web development.
- Multiple answer options for each question.
- Questions are displayed one by one.
- Displays the number of questions already answered.
- Shows the final score at the end of the quiz.
- Beautiful interface design using CSS.

 Technologies Used

- HTML
- CSS
- JavaScript

Project Goal

To reinforce my JavaScript knowledge, practice working with the DOM, arrays, and develop my skills in creating interactive web applications.

 Author

An independent educational project created as part of my web development learning journey.
